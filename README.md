# clickhouse-hackathon

Four people and their agents building on ClickHouse, in parallel, in one repo.

**Start here:**

| File                                                                   | What it is                                                                                                                           |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [AGENTS.md](AGENTS.md)                                                 | How we work: branch discipline, file ownership, how to claim work, how not to clobber each other. **Read before your first commit.** |
| [goal.md](goal.md)                                                     | What we are building. Fill in at kickoff.                                                                                            |
| [TASKS.md](TASKS.md)                                                   | The shared board. Claim a task before writing code.                                                                                  |
| [coordination/journal/BROADCAST.md](coordination/journal/BROADCAST.md) | Things everyone must know. `tail -40` it every session.                                                                              |
| `coordination/journal/<handle>.md`                                     | Your own append-only log and end-of-session handoff.                                                                                 |

The one-line version: **never commit to `main`, only edit files in your lane, claim tasks in
TASKS.md before you start, and write a journal entry before you stop.**
